# System modules (.sprx) on a PS5 at firmware 13.60, from read-only FTP
# directory listings of a jailbroken console. Names and sizes only.
#
# A PS4 app's sandbox mounts /system/common/lib as its only system library
# directory: a running PS4 title's /mnt/sandbox/<title>_000/<random>/common/lib
# lists exactly the same files, and there is no priv/ or system_ex/ in it.
# So sceKernelLoadStartModule("libX.sprx") from a PS4 app can only find modules
# in /system/common/lib; the other directories are listed for reference.
#
# /system/common/lib holds PS4 (backward-compatibility) and PS5 modules side by
# side. Where both exist, the PS5 build is libX.native.sprx and the PS4 build
# libX.sprx. A listing can't tell which format a single libX.sprx is; probes
# from SWRR (a PS4 app) found:
#   - libSceAgc.sprx, libSceAgcDriver.sprx: refused with ENOEXEC (PS5-only);
#   - libSceGnmDriver.sprx, libSceAmpr.sprx: load.
#
# Module names and file names differ for a few libraries: the importing
# module's DT_SCE_NEEDED_MODULE name isn't always the file name.
#   - libSceAppContentUtil is in libSceAppContent.sprx
#   - libSceNpScore is in libSceNpScoreRanking.sprx
#   - libSceSsl: titles link libSceSsl2.prx, but this firmware ships no
#     libSceSsl2.sprx, only libSceSsl.sprx (and libSceLibreSsl*.sprx)
#   - libSceGnmDriver also comes as libSceGnmDriverForNeoMode.sprx (PS4 Pro
#     mode) and libSceGnmDriverCompat1.sprx
#   - libScePosix, libSceCoredump, libSceOpenPsId and libkernel_cpumode_platform
#     are libraries of the libkernel module (libkernel.sprx)
#   - libSceFios2 and libc aren't system modules: titles bundle them in
#     sce_module/
#
