ghostldr

Connect to your PS5

ghostldr runs games inside Star Wars Racer Revenge (SWRR) through Luac0re. Turn the PS5 on, then start Luac0re.

Consoles on your network

Enter the PS5's IP address yourself

On the PS5: Settings → Network → Connection Status → View Connection Status → IPv4 Address.

Start Luac0re on the PS5

  1. Start Star Wars Racer Revenge.
  2. At PRESS START, click the right half of the touchpad.
  3. Go to OPTIONS → HALL OF FAME.
  4. Wait until the loader listens on port 9026.
Never save from SWRR's own menus, and never confirm a “corrupted, will be deleted” prompt.

If the PS5 shows a Luac0re error such as OOB_ARRAY_POINTER … “restart the application to retry”, close SWRR (PS button → SWRR's card → Options → Close Game) and try again. It usually works the next time.

Check the setup

Python, the loader files, this computer's ports and the PS5's loader. Optional, but it finds most problems.

    These checks can't see your firewall: it must allow UDP 18194 and TCP 18195/18196 (how).

            While a game runs, the PS5 connects back to this computer. Your firewall must let Python receive on these ports:
            
    
            
      
            PortWhat forIf it's blocked
            
      
        
            UDP 18194The game's logBlack screen with no log lines here
            
        
            TCP 18195The loader fetches its extension“The PS5 couldn't fetch the extension”
            
        
            TCP 18196The game selector (several games installed)The selector doesn't appear
            
        
            UDP 18196The save manager reports its addressRead the address on the PS5 instead
            
                  
    
            
    
            macOS
            
    
            When asked “Do you want the application python3 to accept incoming network connections?”, click Allow. If you clicked Deny: System Settings → Network → Firewall → Options, find Python and set it to allow incoming connections.
            
    
            Windows
            
    
            When Windows Defender Firewall asks about Python, tick Private networks and click Allow access. Later: Windows Security → Firewall & network protection → Allow an app through firewall → Python → Private.
            
    
            Linux
            
    
            Most desktops have no firewall on. With ufw: sudo ufw allow 18194/udp, sudo ufw allow 18195:18196/tcp and sudo ufw allow 18196/udp. With firewalld, add the same ports to your zone.
